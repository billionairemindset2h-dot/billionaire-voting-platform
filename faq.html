HELP & SUPPORT

Questions about an event?

Here are answers to common questions. If you still need help, contact the team with the event and transaction details.

How do I register?

Open Events / Vote / Register, choose an event, and use its registration form while registration is open. The event page shows any fee and deadline before you continue to payment.

How can I tell if registration is still open?

Choose the event on the home page. Its current status and registration deadline are shown there. A closed event will disable registration.

I paid. Where is my registration confirmation?

After payment, the site verifies the transaction and shows a confirmation. Registration details are also sent to the event team. If you need assistance, email us with your payment reference and the email address used during registration.

How do I vote?

Select an event and contestant, enter the number of votes, and follow the payment instructions shown. Voting availability and deadlines are set for each event.

What should I include when asking for help?

Include your name, event name, payment reference or registration number, and a short description of the issue. Never send card details, passwords, or API keys by email.
